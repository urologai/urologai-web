# Claude Code entry point

Before changing this repository, read:

1. `docs/coordination/AGENT_WORKFLOW.md` — canonical cross-agent workflow.
2. `docs/BUILD_STATE.md` — repository state and permitted next work.
3. The active block brief and prior evidence under `docs/blocks/`.

Do not begin unclaimed work, overlap another open branch or pull request, bypass the Render observation requirement for a material build, or start the next block automatically.

This adapter is intentionally small. Do not copy policy text into it; update the canonical workflow instead.
